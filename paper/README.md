# paper/ — snapshot for the submitted manuscript

What the manuscript prints, frozen at tag `v1.3.3-submission`:

| File | What |
|---|---|
| `numbers.json` | Copy of `results/numbers.json` from which every number in the manuscript is taken |
| `numbers.tex` | LaTeX macros generated from `numbers.json` and the specification constants (`\newcommand` per number) |
| `numbers_values.json` | The macro values as printed, used to attribute every number in the rendered PDF |
| `figures/fig_*.pdf` | Paper figures (circuit-breaker law, energy–miss frontier) and the region figure of the supplement, generated by `code/paper_figs.py --seed 42` from the result files |
| `figures/supp/*.png` | Region plots of the supplement (copies of `results/region_ext/*.png`) |
| `FIGURE_HASHES.txt` | SHA-256 of each figure and of the result files it is drawn from |

The manuscript PDF and its LaTeX source are not part of the artifact. To regenerate the figures after `code/reproduce.py`:

```
python code/paper_figs.py --seed 42 --out paper/figures
```

and compare with `FIGURE_HASHES.txt`. The PDFs are written without a creation date, so with the same matplotlib version (see `requirements.txt`) they are byte-identical.
