# runtime-shield-task-skipping

Artifact for *Optimal Runtime Shields and Machine-Checked Latency Certificate Regions for Embedded Task-Skipping Controllers* (Dat Lam Quoc, FPT School of Business and Technology, FPT University).

Embedded controllers often save energy by skipping invocations of an expensive periodic task; a worst-case guarantee for them is a theorem about the run/skip schedule. This artifact checks such a guarantee against deployed code. The subject is a published frame-skipping perception controller (Deep3, IEEE Internet of Things Journal 2026, DOI [10.1109/JIOT.2026.3740931](https://doi.org/10.1109/JIOT.2026.3740931)). Its latency certificate needs the schedule invariant I_R (never R consecutive skipped frames), and its deployed reuse cap `fsl > W` was off by one; the fix is `fsl >= W`. The controller is composed with a Simplex-style persistent-motion circuit breaker (ASMAG, Journal of Systems Architecture 2026, DOI [10.1016/j.sysarc.2026.104058](https://doi.org/10.1016/j.sysarc.2026.104058)). All controller logic here is re-implemented from a written specification; no Deep3 or ASMAG controller code is included.

## What the artifact shows

| Claim of the paper | Where |
|---|---|
| The lazy shield adds the fewest task activations among only-add enforcers on every trace (Theorem 2); inside the loop of the shipped controller it equals the one-character fix (Proposition 5) | `code/p1_shield_check.py`, `monitor/GateShield.hs`, `code/shield_bridge.py` |
| The generated C of the shield is equivalent to its Copilot specification and memory-safe (copilot-verifier) | `monitor/proof/gate_shield_verify.log` |
| Closed-form certificate regions over detector delay, frame drops and clock rate (Theorem 3); circuit-breaker composition (abstract bound, Section IV-B; exact divisibility law, Proposition 6) | `code/region_bruteforce.py`, `code/region_imitator.py`, `code/cb_rule_ext.py`, `code/imitator_cb_final.py`, `model/` |
| Pre-registered fault-injection (mutant) study (v1.0: 36 mutants; v1.1: +51) | `prereg/`, `code/p1_t4.py`, `code/p2_t4.py`, `code/mutants*.py` |
| Every number printed in the paper | `results/numbers.json` (generated by `code/make_numbers.py`); `paper/numbers.tex` |

## Layout

| Folder | What |
|---|---|
| `model/` | Parametric timed-automaton template (IMITATOR 3.4 `.imi`); the UPPAAL `.xml` is kept as a convenience and was **not independently checked** (no verifier licence) |

| `prereg/` | Pre-registrations v1.0 and v1.1 with their frozen SHA-256. They, and `code/mutants_v11.py` (hashed by v1.1), are kept byte-identical, so they still record the local paths and wording used when they were frozen; the analysis scripts refuse to run if any of them changes |
| `results/numbers.json` | Programmatically extracted numbers (stable + timing) |
| `paper/` | Snapshot of what the manuscript prints: `numbers.json`, the LaTeX macros `numbers.tex`, and the figures (no manuscript PDF); see `paper/README.md` |

| `DATA.md` | Derived inputs, their SHA-256 and how to regenerate them |
| `MANIFEST.txt` | SHA-256 of every tracked file (checked by `code/c7a_check.py` against an anonymous download of the tag) |
| `REPRO_CHECK.md` | Key-by-key comparison of `numbers.json` from a fresh copy and a new virtual environment: 1313 of 1313 compared stable keys identical, with one documented exception (below) |

## Reproduce

```
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt          # .venv/bin/pip on Linux
set THS_DATASETS=<folder with the derived inputs>      # see DATA.md; default ./datasets
python code/reproduce.py --seed 42 --check paper/numbers.json          # Python steps
python code/reproduce.py --seed 42 --tools --check paper/numbers.json  # + Copilot, IMITATOR, gcc (WSL)
python code/region_imitator.py --seed 42 --only base,d_pipe,d_block,b,d_b_pipe,d_b_block,kappa,d_kappa_b_block   # full IMITATOR grid (~45 min)
```

Every script takes `--seed` (default 42).

**IMITATOR runs without result.** The six breaker runs of the template encoding in `code/region_imitator.py` (`CB_k1-1_ge/gt`, `CB_d_pipe_k1-1_ge/gt`, `CB_d_block_k1-1_ge/gt`) produce no result in either the original run or the reproduction. The paper does not count them: its breaker checks use the discrete encoding of `code/imitator_cb_final.py`.
- Five of them exit with code 124 (900 s timeout) both times.
- `CB_d_block_k1-1_gt` exited with code 1 after 407 s in the original run (cause not determined) and with code 124 at the timeout in the reproduction.

`make_numbers.py --check` therefore compares that run's `returncode` like the volatile `wall_s` keys. This is the only stable key treated this way (`CHECK_AS_VOLATILE` in `code/make_numbers.py`).

## Data policy

No frames, ground truth or detection dumps are redistributed: the licences of CDnet2014, LASIESTA and BMC 2012 do not record permission to redistribute derived data. `DATA.md` lists the derived inputs with SHA-256 and the scripts that regenerate them from the public datasets.
